# CS-330
Repository created for CS 330 portfolio

How do I approach designing software?

Working on my 3D scene gave me a different way to think about software design because I had to picture what I wanted something to look like before deciding how to build it. I started with larger ideas like a desk, monitor, mug, and pencil, then broke each one down into basic shapes that I could scale, rotate, and position. I found that it worked best for me to focus on one object at a time and get its basic shape and placement right before worrying about smaller details like textures or lighting. That same approach can carry into future work because breaking a bigger problem into smaller pieces makes it easier to understand what needs to be built and where something is going wrong.

How do I approach developing programs?

The biggest part of my development process was iteration. I rarely made a large group of changes at once. I would change one value or one section of code, run the program, see what happened, and then decide what needed to change next. That became especially important when I was positioning smaller objects like the pencil or working with lighting, where even a small change could have a much bigger effect than I expected. As the course went on, I became more comfortable testing ideas instead of expecting everything to work on the first attempt. I also got better at leaving parts of the scene alone once they were working instead of continuing to change them and accidentally creating a new problem somewhere else.

How can computer science help me in reaching my goals?

Computer graphics was completely new to me when I started this course, and I did not expect to enjoy it as much as I did. I still do not see graphics as the main direction I want to take professionally, but learning how a 3D scene is built gave me experience with problem solving, debugging, organizing code, and working through something that did not always have an obvious answer. Those skills will carry into future programming courses and eventually into software development work. The course also sparked an interest in graphics that I would like to keep exploring on my own. Being able to make a change in the code and immediately see the result on the screen made the work feel more like experimenting than just completing an assignment, and I would like to continue building on that experience.
